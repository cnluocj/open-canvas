## ⚠️ 数据使用原则（重要！）

### 关于本模版中的数据

本模版中的所有示例数据均已进行**参数化处理**，使用 `[占位符]` 格式代替具体数值，以避免AI在生成内容时记忆和复制特定数据，确保生成内容的灵活性和多样性。

### 占位符系统说明

本模版使用以下占位符替代具体数据：

| 占位符类型 | 示例 | 说明 |
|----------|------|------|
| `[年龄]` | `[年龄]岁` | 代替具体年龄数字 |
| `[性别]` | `[性别]性` | 代替"男"或"女" |
| `[时长]` | `[时长] h`、`[时长]年` | 代替时间长度 |
| `[数值]` | `SpO₂ [数值]%` | 代替检查结果数值 |
| `[剂量]` | `阿司匹林[剂量] mg` | 代替药物剂量 |
| `[频次]` | `[频次]次/d` | 代替给药频次 |
| `[分数]` | `GRACE评分[分数]分` | 代替评分结果 |
| `[年份]`/`[月份]`/`[日期]` | `[年份]年[月份]月[日期]日` | 代替具体日期 |
| `[地点]` | `居住于[地点]` | 代替地点名称 |
| `[姓氏]` | `患者[姓氏]某某` | 代替患者姓名 |

### 数据替换原则

**保持不变的内容：**
- ✅ **疾病名称**：急性心肌梗死、慢性阻塞性肺疾病等
- ✅ **药物名称**：阿司匹林、氯吡格雷、呋塞米等
- ✅ **医学术语**：PCI、LVEF、BNP、SpO₂、GRACE评分等
- ✅ **解剖结构**：右冠状动脉、左心室、主动脉瓣等
- ✅ **检查项目**：心电图、血常规、胸部CT等
- ✅ **参考范围描述**：如"参考范围3.5~5.5 mmol/L"
- ✅ **单位**：mg、mL、mmHg、℃等

**需要替换的内容：**
- 🔄 **具体年龄、性别**：[年龄]岁、[性别]性
- 🔄 **具体数值**：检查结果、生命体征数据
- 🔄 **具体时间**：日期、时长、疗程
- 🔄 **剂量、频次**：药物用量和用法
- 🔄 **地点、人名**：[地点]、[姓氏]某某

### 使用指南

在使用本模版生成病案报告时：
1. **AI生成阶段**：使用占位符格式，让AI理解内容结构和逻辑关系
2. **数据填充阶段**：根据实际病例，将占位符替换为真实数据
3. **参考附录**：如需了解完整病例的实际写作效果，可参考文末"附录：完整未脱敏病例示例"

### 附录说明

本模版末尾提供了**一个完整的未脱敏病例示例**（急性心肌梗死案例），展示真实数据下的完整病案报告写作效果。该附录仅供**理解内容组织方式和写作风格参考**，不应直接用于AI训练或生成。

## 📝 写作风格指南

### 1. 段落 vs 列表的使用原则

#### **使用段落的场景（主要）**
- ✅ **现病史叙述**：用流畅的段落描述病情发展、就诊经过
- ✅ **诊断依据阐述**：用段落论证诊断的合理性
- ✅ **治疗方案描述**：用段落详细说明用药依据、剂量调整过程
- ✅ **讨论分析**：用段落进行深入的诊疗思路分析
- ✅ **疗效描述**：用段落叙述患者的改善情况和随访结果

#### **使用列表的场景（辅助）**
- ✅ **诊断罗列**：主要诊断、合并诊断、鉴别诊断
- ✅ **辅助检查结果**：实验室指标、影像学检查
- ✅ **用药清单**：多种药物的列举（但具体用法用段落描述）
- ✅ **手术步骤**：手术关键步骤的简要罗列

### 2. 句式结构要求

#### **句子长度**
- 简单陈述：15-25字
- 复杂描述：25-45字
- 长句可用，但避免超过60字，注意断句和标点

#### **句式变化示例**

📌 **数据替换说明**：以下示例中的数值、时间等已参数化。生成内容时，AI应理解逻辑关系而非记忆具体数值，实际应用时根据病例填入真实数据。

```
✅ 好的示例：
"患者入院后完善相关检查，心电图示广泛前壁导联ST段抬高，肌钙蛋白I显著升高
（[数值] ng/mL），结合临床表现，诊断为急性ST段抬高型心肌梗死。根据《急性心肌梗死
诊断和治疗指南》，患者符合急诊PCI指征，遂立即启动导管室，行冠状动脉造影术。
造影显示左前降支近段完全闭塞，TIMI血流0级，予以球囊扩张后植入药物洗脱支架1枚，
血管成功再通，TIMI血流恢复至3级，术中及术后无并发症。"

❌ 避免的写法：
"患者心肌梗死，做了造影，放了支架，手术成功。"（过于简略）
"患者入院后心电图示ST段抬高肌钙蛋白升高诊断心肌梗死行PCI术造影示血管堵塞放支架后血管开通..."
（标点缺失，句子过长混乱）
```

### 3. 信息密度控制

#### **详细描述的部分**
- 诊断依据和鉴别诊断的论证过程
- 治疗方案选择的理由和依据
- 用药剂量、调整过程、监测指标
- 手术关键步骤、术中发现、并发症处理
- 疗效评价的量化数据和时间节点
- 讨论部分的理论分析和循证依据

#### **简略描述的部分**
- 常规查体正常结果（可一笔带过）
- 标准化的辅助检查（仅列关键异常值）
- 常规对症治疗（可概括性描述）

### 4. 专业语言规范

#### **诊断表述**
```
✅ "根据患者症状、体征及辅助检查，诊断为..."
✅ "符合《XX诊疗指南》的诊断标准"
✅ "结合病史、实验室检查及影像学表现，诊断明确"
❌ "觉得患者是XX病"、"可能是XX"

✅ "鉴别诊断：需与XX疾病鉴别，该病特点为...，本例患者..."
❌ "排除了XX病"（应说明鉴别要点）
```

#### **治疗方案表述**
```
✅ "遵医嘱予以阿司匹林[剂量] mg口服，[频次]次/d，长期抗血小板治疗"
✅ "考虑患者肾功能不全，调整抗生素剂量为常规剂量的50%"
✅ "基于患者高出血风险（HAS-BLED评分[分数]分），谨慎使用抗凝药物"
❌ "给了阿司匹林"、"用了点抗生素"

✅ "治疗[时长] d后复查血常规示白细胞从[初始值]×10⁹/L降至[终末值]×10⁹/L，
    CRP从[初始值] mg/L降至[终末值] mg/L，感染指标明显改善"
❌ "用药后感染好转"
```

#### **时间表述规范**
```
✅ "入院第X天"、"术后第X天"、"治疗X周后"
✅ "[年份]年[月份]月[日期]日"、"X月X日"
✅ "持续治疗[时长]天/周/月"
✅ "随访[时长]个月"
❌ "过了几天"、"不久之后"、"很快"
```

## 摘要

### 写作要点
1. 第一句：简要介绍患者（年龄、性别、主要诊断）
2. 第二句：病情特点、诊断难点或治疗难点
3. 第三-四句：主要治疗措施（包括中西医结合治疗）
4. 第五句：治疗效果（量化数据）
5. 最后一句：临床意义和价值
6. 字数：200-300字
7. **使用一个完整段落，不分段不分行**

### ❌ 常见错误示例

```
❌ 过于简略：
"本文报告一例心肌梗死患者。患者胸痛，做了支架，恢复良好。"
（缺乏具体诊断、治疗细节和数据）

❌ 过度列表化：
"患者情况：
- 年龄[年龄]岁
- 性别[性别]
- 诊断：心肌梗死
治疗方法：
- 药物治疗
- 介入治疗"
（摘要应为完整段落，不应使用列表）

❌ 缺乏量化数据：
"患者心肌梗死，经治疗后病情好转，效果满意。"
（应提供具体的心肌标志物、LVEF等数据）

❌ 缺乏临床意义：
"本例患者经过治疗康复出院。"
（应总结本案例的特殊性、临床价值、对实践的启示）
```

## 引言（可选但推荐）

### 写作要点
- 疾病的流行病学背景和临床重要性
- 诊疗难点或挑战
- 本案例的特殊性
- 报告的目的和意义
- 字数：300-500字

### 示例（参数化版本）

📌 **数据替换说明**：引言中涉及的流行病学数据、统计比例等（如"死亡率可增加2~3倍"）通常来自文献，可保持相对稳定。患者具体信息（年龄、性别、症状、时间等）使用占位符。

```
急性心肌梗死（AMI）是心血管系统最危急的疾病之一，以心肌缺血坏死为主要特征，
典型表现为剧烈胸痛。然而，部分患者症状不典型，可表现为上腹不适、乏力、呼吸困难、

漏诊和误诊风险，导致诊断延迟，错失最佳治疗时机，患者死亡率可增加2~3倍[2]。
因此，提高基层医生对不典型AMI的识别能力，优化首诊流程及转诊机制，
对改善患者预后至关重要。

本案例报告一例[年龄]岁[性别]性患者，以"突发呼吸困难"为主要表现，无典型胸痛，
在社区医院首诊。社区医生通过详细问诊、仔细查体、及时心电图检查，成功识别出
急性下壁心肌梗死，立即启动"心梗急救一包药"和区域胸痛中心绿色通道，
实现快速转诊和血管再通。本例的成功救治凸显了社区医院在急性心肌梗死早期
识别和处理中的关键作用，验证了基层-上级医院协同救治模式的有效性。
通过本案例分析，旨在为基层医生处理症状不典型AMI提供实践参考，强调
"高度警惕+规范流程+快速转诊"的重要性。
```

## 正文

## 一、临床资料

### 1. 一般资料/基本情况

#### 写作要求
- **使用流畅的段落**描述，避免过度列表
- 按逻辑顺序组织：人口学信息→主诉→现病史→既往史→个人史/家族史
- 现病史要详细，包括起病时间、症状特点、就诊经过、治疗反应
- 时间线要清晰

#### 示例1：症状不典型的急性心肌梗死（参数化版本）

随访情况：出院后1个月门诊随访，患者病情稳定，无胸痛、呼吸困难，
日常生活活动不受限。复查心电图示陈旧性下壁心肌梗死表现，心脏超声LVEF 56%。
复查血脂：LDL-C 1.7 mmol/L，达标。出院后3个月电话随访，患者规律服药，
坚持康复锻炼，无心血管不良事件（心绞痛、心力衰竭、再次心肌梗死、卒中、死亡）。
